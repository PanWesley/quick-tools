# 标签分级管理 — 设计文档

**日期**: 2026-06-11
**状态**: 已确认

## 概述

将标签系统从扁平列表升级为两级树形结构（分组 → 标签），支持系统预设分组、自由创建分组、标签在分组间移动。概览和账单明细中支持按分组或按标签筛选。

---

## 一、数据模型

### 1.1 新增 STORE_TAG_GROUPS（标签分组表）

```js
// IndexedDB 新建 store
db.createObjectStore('tagGroups', { keyPath: 'id' });

// 记录结构
{
  id: "group-payment",     // 唯一标识
  name: "支付方式",          // 分组名称
  color: "#3498db",        // 分组颜色
  order: 0,                // 排序权重 (越小越靠前)
  createdAt: "2026-06-11"  // 创建时间
}
```

### 1.2 修改 STORE_TAGS（标签表）

在现有 `{ id, name, color }` 基础上增加一个可选字段：

```js
{ id, name, color, parentId }  // parentId 指向 tagGroups.id，null 表示未分组
```

### 1.3 预设分组

首次初始化时自动创建以下 4 个分组，所有现有标签默认归入"消费类型"：

| id | name | color | order |
|----|------|-------|-------|
| group-payment | 支付方式 | #3498db | 0 |
| group-person | 人员 | #e91e63 | 1 |
| group-category | 消费类型 | #f39c12 | 2 |
| group-channel | 渠道 | #9b59b6 | 3 |
| group-uncategorized | 未分类 | #95a5a6 | 99 |

### 1.4 数据迁移

升级时检测 STORE_TAG_GROUPS 是否存在：
- 不存在 → 创建分组表 + 插入预设分组 → 所有现有标签的 parentId 设为 "group-category"
- 已存在 → 跳过

## 二、标签管理页 UI

### 2.1 树状结构

```
🏷️ 标签管理
┌─ 新建分组 ─────────────────────────────┐
│ [输入名称...]  [🎨]  [+ 创建]           │
└────────────────────────────────────────┘

┌─ 📁 支付方式 ──────────────────────────┐
│  🏷️ 微信     15笔  [🎨] [✏️] [📦→] [🔀] [🗑️] │
│  🏷️ 支付宝    8笔  [🎨] [✏️] [📦→] [🔀] [🗑️] │
│  🏷️ 抖音      3笔  [🎨] [✏️] [📦→] [🔀] [🗑️] │
│  [+ 新建标签到此分组]                     │
└────────────────────────────────────────┘

┌─ 📁 人员 ──────────────────────────────┐
│  ...                                    │
```

### 2.2 交互行为

| 操作 | 行为 |
|------|------|
| 点击分组名 | 折叠/展开子标签列表 |
| 分组名旁 [✏️] | 内联编辑分组名 |
| 分组名旁 [🗑️] | 删除分组，子标签移入"未分类" |
| 标签 [🎨] | 修改标签颜色（保持现有交互） |
| 标签 [✏️] | 重命名标签（保持现有交互） |
| 标签 [📦→] | 移动到其他分组（弹出选择框） |
| 标签 [🔀] | 合并标签（保持现有交互） |
| 标签 [🗑️] | 删除标签（保持现有交互） |
| 点击使用次数 | 跳转到列表按该标签筛选 |
| 拖拽标签 | 拖到其他分组即完成移动 |

### 2.3 新建标签时指定分组

新建表单增加分组选择下拉框，默认选中当前展开的分组或"未分类"。

## 三、概览页筛选

### 3.1 标签弹出层

点击"🏷️ 标签"按钮弹出：

```
┌─────────────────────────────────┐
│ 选择标签                    [✕] │
├─────────────────────────────────┤
│                                 │
│ 📁 支付方式          [选中全部]   │ ← 点击"选中全部"筛选该分组所有子标签
│   🏷️ 微信                       │ ← 点击选择单个标签
│   🏷️ 支付宝                     │
│   🏷️ 抖音                       │
│                                 │
│ 📁 人员              [选中全部]   │
│   🏷️ 宝贝                       │
│   🏷️ 家庭                       │
│   🏷️ 个人                       │
│                                 │
│ 📁 消费类型          [选中全部]   │
│   ...                           │
│                                 │
├─────────────────────────────────┤
│ [清除]              [确定筛选]    │
└─────────────────────────────────┘
```

### 3.2 筛选逻辑

- 选中"全部"分组 → 将分组下所有 tag id 加入 selectedTagIds
- 选中单个标签 → 将该 tag id 加入 selectedTagIds
- 支持跨组多选（如同时选"微信"和"宝贝"）
- 已选标签在弹出层外部显示为 chip（带分组前缀：`支付方式 / 微信`）

## 四、记账表单

### 4.1 智能输入增强

现有智能匹配逻辑保持不变，增强：
- 搜索结果中显示分组信息：`微信 (支付方式)`
- 选中后 chip 显示为分组色块 + 标签名
- 自然语言输入无需改变

### 4.2 标签输入字段

输入标签时不需要指定分组 — 分组是标签的固有属性，选标签即自带分组。

---

## 五、图表筛选

图表中增加按分组聚合的选项：
- 饼图中可选"按分组"或"按标签"展示
- 按分组时：所有子标签金额汇总到分组名

## 七、向后兼容

- 所有现有 API（getTags、addTag、updateTag、deleteTag、mergeTag）保持不变
