# Time 快捷编辑器紧凑布局设计

状态：已获用户逐段确认  
日期：2026-07-24  
基线：`fix/time-quick-editor-scroll-lock` / 草稿 PR #19

## 背景

真机截图和 390×844 当前实现显示两个主要问题：

1. 键盘主输入态仍保留 44px 的装饰性滑动指示区，加上宽松的输入、工具栏和底部安全区间距，面板显得厚重。
2. 日期态同时显示标题、备注、快捷工具、摘要和日期内容，重复层级占据约三分之一首屏；用户无法通过明确的“取消 / 确认”结束整次日期编辑。

用户选择视觉方案 A“平衡紧凑”：保留主面板的单行备注和完整快捷能力，同时让日期面板独占弹层。

## 目标

- 移除无功能的顶部滑动指示及其占位。
- 将 390×844 下的键盘主输入面板压缩到 170–180px，保持简洁、舒适和可点击性。
- 日期态隐藏标题面板，完整展示日期、时间、提醒、重复和底部操作栏。
- 日期编辑具备真正的临时状态：取消回滚、确认提交。
- 退出日期态后回到标题输入，并重新呼出键盘。
- 保留现有滚动锁、背景隔离、草稿、编辑事项和详细信息行为。

## 非目标

- 不把整个快捷编辑器改成全屏编辑器。
- 不把备注移入“更多设置”。
- 不重构优先级、归属、背景色等小型替换面板。
- 不使用 `contenteditable`、修改焦点顺序或其他手段规避 iOS 键盘导航栏。
- 不声称桌面浏览器可以替代 iPhone 真机键盘验收。

## 选定方案

### 1. 键盘主输入态

主面板从上到下只包含：

1. 标题输入；
2. 单行备注；
3. 44px 快捷工具与 44px 保存按钮；
4. 单行日程摘要。

具体布局约束：

- 删除 `quick-drag-handle` 的 HTML、缓存元素和全部 CSS。
- 输入区水平边距保持 16px 左右，减少顶部、标题、备注之间的垂直空白。
- 标题仍是视觉主项；备注字号与颜色降一级，但保持可直接点击编辑。
- 快捷按钮不缩小点击目标，只压缩工具栏外部上下间距。
- 摘要保持单行；空间不足时省略，不增高主面板。
- 仅在键盘主输入态移除多余的 `env(safe-area-inset-bottom)` 留白；非键盘弹层仍保留必要安全区。
- 390×844 浏览器视口中，主面板高度必须不高于 180px。

### 2. 日期独占态

点击“日期时间”后：

- 主输入区、快捷工具栏和摘要全部隐藏；
- 键盘收起；
- 日期面板占据整张底部弹层；
- 顶部直接从“开始 / 结束”标签进入日历，不再显示滑动指示或重复标题；
- 时间、提醒、重复设置保留在日历下方；
- 底部固定双按钮“取消 / 确认”。

日期面板允许内部滚动，但在 390×844 的默认月份布局中，应首屏完整显示：

- 开始 / 结束标签；
- 月份与日历；
- 快捷日期；
- 时间、提醒、重复；
- 取消、确认。

### 3. 其他快捷面板

优先级、归属、背景色仍按现有替换面板交互工作，不扩大本次改动。详细信息继续全屏显示，返回后仍聚焦标题并呼出键盘。

## 状态与数据流

日期会话状态由快捷编辑器状态模块中的纯数据结构管理，页面控制器只负责渲染、焦点和把最终结果写回表单。会话包含 `original` 和 `draft` 两份日程字段，避免在取消时依赖反向 DOM 恢复。

### 进入日期态

从键盘态打开日期页时，创建一份“日期会话”，其 `original` 和 `draft` 初始值相同，包含：

- 开始日期、结束日期；
- 全天 / 指定时间模式；
- 开始时间、结束时间；
- 提醒及自定义提醒；
- 重复及自定义重复。

标题、备注、优先级、归属和背景色不属于日期快照。

### 日期编辑

日期主页和时间、提醒、重复二级面板只编辑日期会话的 `draft`；确认整个日期会话前，不写回事项表单或持久化创建草稿。二级面板：

- 确认后合并到日期临时草稿并返回日期主页；
- 取消后丢弃该二级修改并返回日期主页；
- 不直接回到键盘。

### 取消日期

点击日期页“取消”、按硬件 Escape 或触发等价返回动作时：

1. 丢弃日期会话；事项表单继续保持进入日期态前的原值；
2. 关闭日期面板；
3. 回到键盘主输入态；
4. 将焦点放回标题输入末尾并呼出键盘。

取消日期不会关闭整个事项编辑器。

### 确认日期

点击“确认”时：

1. 校验日期范围和时间范围；
2. 校验失败则在日期页就地提示并保留当前面板；
3. 校验成功则把日期会话 `draft` 一次性合并到事项草稿并持久化；
4. 清除日期会话；
5. 回到标题输入末尾并呼出键盘。

### 整个事项关闭

点击遮罩关闭整个编辑器时，沿用现有创建草稿和编辑恢复规则。若日期会话仍打开，应先丢弃未提交的日期会话，再执行整个事项关闭，避免半提交的日程设置泄漏。

## 焦点与滚动

- 键盘主输入态继续阻止文档级触摸滚动。
- 日期主页、时间、提醒、重复和滚轮选择器允许自身内部滚动。
- 日期页取消、确认和 Escape 返回后，标题输入重新获得焦点。
- 日期页打开时，焦点进入“开始”标签或当前选中日期；底部操作按钮始终在正常焦点顺序中。
- 背景页面继续保持 `inert` 和 `aria-hidden`。

## iOS 键盘导航栏边界

iPhone 键盘上方的上一项、下一项和完成栏由 iOS/Safari 提供。Web 页面或安装到主屏幕的 PWA 没有受支持的 CSS/JavaScript API 可以移除它。

Apple 的 `UITextInputAssistantItem` 属于 UIKit 原生接口，且 Apple 文档说明 iPhone 会忽略该对象的内容。它不是 Safari/PWA 可使用的网页接口。

本次只减少网页面板自身与系统导航栏之间的空白，不采用以下高风险规避方式：

- 将输入框改为 `contenteditable`；
- 从焦点顺序删除备注；
- 伪造自定义键盘；
- 依赖私有 WebKit 行为。

参考：<https://developer.apple.com/documentation/uikit/uitextinputassistantitem>

## 无障碍

- 主对话框和日期独占态保持可识别名称。
- 所有工具、设置行、取消和确认按钮的点击目标至少 44×44px。
- “取消 / 确认”使用明确文本，不仅依赖颜色。
- 日期或时间校验错误以可见文本和 `aria-live` 通知。
- 隐藏主输入区时同步处理其可访问性与焦点，不能只做视觉透明。
- 减少动画偏好下不新增位移动画。

## 错误处理

- 结束日期早于开始日期：沿用现有自动校正到开始日期的策略，并通过现有提示机制告知用户。
- 同日结束时间不晚于开始时间：日期页就地提示，不返回键盘。
- 待定日期清除时间、提醒和重复时：保留现有二次确认；取消二次确认返回日期主页。
- 日期会话状态缺失或异常时：退化为当前事项草稿，仍允许安全返回键盘，不能关闭或损坏整个事项。

## 验收标准

### 自动化

- 源码契约确认滑动指示 HTML、缓存元素和 CSS 均已删除。
- 运行时测试确认主输入态高度类和日期独占态切换正确。
- 日期取消恢复全部日程字段和自定义设置。
- 日期确认保留全部日程字段。
- 时间、提醒、重复二级确认与取消都返回日期主页。
- Escape 在日期态执行日期取消，不关闭事项编辑器。
- 日期退出后标题重新聚焦。
- 键盘态滚动锁与日期内部滚动均不回归。
- 页面、Service Worker 和缓存契约同步升级。

### 390×844 浏览器

- 主输入面板高度不超过 180px。
- 标题、单行备注、工具按钮、保存和摘要均完整可用。
- 日期态完全不显示主输入区和工具栏。
- 日期首屏完整显示日历、三项设置和底部操作栏。
- 取消回滚、确认提交、焦点恢复和背景 `inert` 均可观察。

### iPhone 真机

- 键盘弹出后主面板明显低于当前版本，面板与系统导航栏之间无额外网页留白。
- 面板和底层页面不可滑动。
- 日期页收起键盘并独占弹层。
- 日期取消、确认均返回标题输入和键盘。
- 系统键盘导航栏仍可见但不与网页面板重叠。
