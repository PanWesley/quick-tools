# 今日有序新增事项交互重构设计

日期：2026-07-22

## 目标

把新增事项从一组互相叠加的弹框，重构为一个持续存在、不会意外丢失输入的编辑会话。交互参考用户提供的「指尖时光」截图，同时保留今日有序现有的晨光手账视觉、字段能力和本地优先架构。

成功标准：

- 点击新增后，标题输入框在同一次用户操作中获得焦点；支持键盘的平台会呼出键盘。
- 编辑会话打开期间，背景页面不能滚动，任务列表的左右滑动操作也不响应。
- 键盘、日期、优先级、归属、背景色等快捷面板互斥，同一时刻只显示一个输入面板。
- 日期面板包含开始、结束两个阶段，并能设置开始/结束时间、提醒和重复。
- 时间、提醒、重复的二级选择完成或返回后回到日期主面板，不关闭新增事项。
- 详细信息是真正覆盖整个视口的全屏页；返回后回到简洁编辑器并重新聚焦标题。
- 点击蒙层或下滑可关闭新增事项；未保存的新建草稿会被保留，下次新增时继续编辑。
- 保存成功后清除草稿；标题为空时不能保存。

## 已确认的问题

当前版本已经实现自动聚焦、底部输入面板、快捷按钮、日期日历和详细编辑，但缺少统一的编辑状态模型：

1. `openSheet()` 能让 `quick-title` 获得焦点，但没有锁定 `body`，全局任务滑动监听仍然存在。
2. 快捷按钮通过反复清空并重建 `quick-extra-panel` 切换，键盘、父面板和二级选择器分别由不同逻辑管理。
3. 新版时间入口把配置对象传给只接受 `start/end` 字符串的旧选择器，回调没有被消费；当前只能落成单一时间点。
4. 时间轮盘使用独立 backdrop 叠在日期面板上，不是同一区域内的层级切换。
5. `.quick-full-panel` 位于带 `transform` 的 `.quick-sheet-v2` 内，`position: fixed` 被底部面板建立的包含块限制，因此没有真正全屏。
6. 时间、重复、提醒选完后的返回目标依赖“旧面板仍在背后”，而不是明确的父子导航规则。

## 方案选择

采用“单一编辑会话 + 显式面板状态机”。

不继续给现有弹框逐点打补丁，因为局部修复仍会留下焦点、弹层和返回目标相互耦合的问题；也不整体重写工具，以免扩大到与本次新增体验无关的页面。

## 编辑状态模型

新增一个独立的快速编辑器状态模块，负责状态转换，不直接操作 DOM：

```text
session: closed | open
surface: keyboard | date | priority | area | tone | detail
dateChild: none | time | reminder | repeat
datePhase: start | end
mode: create | edit-task | edit-habit
```

核心规则：

- `session=closed` 时不显示任何编辑器层。
- `surface=keyboard` 时标题或备注输入框聚焦，快捷扩展区域隐藏。
- `surface=date|priority|area|tone` 时输入框失焦，扩展区域替换键盘占用的空间。
- `surface=date` 才允许 `dateChild`；二级面板确认或返回后统一将 `dateChild` 设为 `none`。
- 点击其他快捷按钮时直接替换 `surface` 并清空 `dateChild`，不经过关闭编辑会话。
- `surface=detail` 时显示根节点全屏页；退出详情统一回到 `surface=keyboard`。
- 点击当前已打开的快捷按钮回到 `surface=keyboard`，并在该点击事件中同步聚焦标题。

状态模块使用纯函数导出转换结果，DOM 层只负责渲染结果和执行一次性的焦点、滚动锁动作，避免业务状态散落在点击处理器中。

## 草稿数据

统一草稿结构：

```text
title, notes, priority, area, tone
startDate, endDate
timeMode, startTime, endTime
repeat, customRepeat
reminder, customReminder
```

- 现有 `date` 字段继续代表开始日期，新增可选 `endDate`；旧数据没有 `endDate` 时按开始日期处理。
- 结束日期默认等于开始日期，不得早于开始日期。
- 结束时间仅在设置开始时间后出现，默认预填开始时间后一小时；结束日期相同时，结束时间必须晚于开始时间。
- 跨日事项在日历覆盖的每个日期展示，首尾日期显示时间，中间日期显示为持续事项。
- 重复规则以开始日期为锚点；提醒默认针对开始时间。
- 待定事项清空开始/结束日期、时间、重复和提醒。

新建草稿持久化到本地偏好键 `today-youxu-quick-draft-v1`：

- 标题、备注或任一非默认设置变化后保存草稿。
- 点击蒙层、下滑关闭、切换页面或应用进入后台时保存。
- 下次点击新增时恢复草稿；没有草稿时使用今天、生活、重要不紧急等现有默认值。
- 保存成功后清除草稿。
- 编辑已有任务或习惯不覆盖新建草稿；本次持久化只覆盖新建流程。

## 交互流程

### 打开与关闭

1. 点击新增按钮。
2. 建立编辑会话并恢复草稿或默认值。
3. 显示底部编辑器、锁定背景滚动、暂停全局左右滑动处理。
4. 强制一次布局后，在原点击事件栈内聚焦标题，将光标置于末尾。
5. 点击蒙层或向下拖动超过阈值时保存草稿并关闭；背景滚动位置保持不变。

下拉关闭手势只从编辑器顶部拖拽区开始，避免与日历、色板、列表和滚轮本身的纵向操作冲突。拖动未达到阈值时回弹。

### 快捷面板

- 点击日期、优先级、归属或背景色：输入框失焦，键盘收起，对应内容在编辑器下半区出现。
- 点击另一个快捷按钮：原内容直接被新内容替换，顶部标题、备注、工具栏和发送按钮保持不动。
- 选择优先级、归属、背景色后不自动关闭面板；选中态立即更新，用户可继续比较或切换到其他面板。
- 工具按钮使用图标颜色和小圆点表达已设置状态；在工具栏上方增加单行摘要，显示日期范围、时间和重复/提醒等最重要结果。

### 日期主面板

- 顶部为“开始 / 结束”两个阶段；开始为默认阶段，待定保留为月历下方的快捷日期。
- 中部沿用当前内嵌月历，但周末、今天和选中日期的视觉层级参考用户截图。
- 选择开始日期后，如果结束日期为空或更早，结束日期同步为开始日期。
- 选择结束阶段后设置结束日期；返回开始阶段不会丢失结束值。
- 月历下方保留今天、明天、周末、待定快捷日期。
- 底部使用四行清晰的设置项：时间、提醒、重复；时间行同时摘要开始与结束，例如 `09:00–10:00`。

### 时间、提醒与重复

- 点击时间进入同一区域内的二级面板，不再打开新的全局 backdrop。
- 时间面板提供开始和结束两个页签，采用现有滚轮控件；全天开关位于面板底部。
- 确认时间后回到日期主面板，并刷新时间摘要。
- 提醒面板保留无、准时、常用提前量和自定义；确认或返回都回到日期主面板。
- 重复面板补齐无、每天、工作日、每周、每月和自定义；确认或返回都回到日期主面板。
- 取消二级编辑时恢复进入该面板前的临时值；确认才写入草稿。

### 详细信息

- 将详细页 DOM 移到 `quick-sheet` 外、与底部编辑器同级，避免 transform 包含块限制。
- 全屏页覆盖安全区，拥有独立标题栏、返回和完成按钮，并锁定背景。
- 标题、备注和所有设置与同一个草稿对象双向同步。
- 详情里的日期、优先级、归属、重复、提醒和背景色进入全屏页内部的子视图，不短暂露出底部编辑器。
- 点击返回或完成都回到简洁编辑器；完成只表示结束详细设置，不直接保存事项。
- 返回后在同一次点击处理里恢复标题焦点并呼出键盘。

## 滚动、键盘与动画

- 编辑会话打开时记录 `scrollY`，用固定 body 或等价的滚动锁方案保持页面位置；关闭时恢复。
- 全局任务滑动处理器在编辑会话打开时立即返回，防止蒙层下的任务被滑动。
- 编辑器内部仅允许当前面板自身滚动；滚到边界时不把滚动链传给背景。
- 布局高度优先使用 `visualViewport.height`，并通过 CSS 变量适配 iOS 键盘高度变化。
- 自动聚焦路径不对编辑器根节点使用从屏幕外进入的 transform 动画；面板内容可以做轻微淡入。
- 支持 `prefers-reduced-motion`，关闭非必要过渡。

## 视觉与可访问性

- 保留现有晨橙、暖白、圆角和图标体系，不引入新的视觉主题。
- 底部编辑器始终保持标题、备注、工具栏、发送按钮的稳定位置，减少切换时的跳动。
- 所有触控目标最小 44×44px；轮盘选择、日期和页签提供明确选中态。
- 快捷按钮使用 `aria-pressed`，面板标题和二级返回拥有可读名称。
- 打开编辑器时把焦点送入弹层；关闭时返回触发新增的按钮。
- 全屏详情和底部编辑器分别维护焦点范围；背景内容在会话期间不可交互。
- 保存失败、结束早于开始、提醒不可用等错误使用可读状态提示，不能只依赖颜色。

## 校验与错误处理

- 标题去除首尾空白后为空：发送按钮禁用，提交时再次拦截。
- 结束日期早于开始日期：自动同步到开始日期并提示。
- 同日结束时间不晚于开始时间：保留二级面板并显示错误，不提交临时值。
- 选择待定：二次确认清理时间/重复/提醒相关字段，避免隐式丢失已设置内容。
- 草稿解析失败：丢弃损坏草稿并使用默认值，不影响本地任务数据库。
- 数据库保存失败：编辑器保持打开、草稿保留并显示错误。

## 代码边界

- 新增 `tools/time/js/quick-editor-state.js`：状态转换、草稿归一化和校验纯函数。
- 新增 `tools/time/js/quick-editor-state.test.js`：状态与数据规则单元测试。
- `tools/time/js/app.js`：保留数据保存与现有渲染入口，改为根据状态渲染快速编辑器；移除新版入口对旧选择器参数的错误适配。
- `tools/time/index.html`：调整详细页层级，补充稳定的编辑器容器和无障碍属性。
- `tools/time/css/style.css`：滚动锁、输入区域高度、父/子面板替换、真正全屏详情和移动端安全区。
- `tools/time/sw.js`、资源查询版本和 CHANGELOG：实现完成后按项目现有发布规则更新。

不重构通知后端、主导航、任务列表视觉或其他工具页面。

## 测试与验收

### 自动测试

- 状态机：打开、关闭、同按钮返回键盘、不同按钮替换、二级确认/取消返回父面板、详情返回。
- 草稿：默认值、持久化恢复、保存清除、损坏数据降级、编辑已有事项不覆盖新建草稿。
- 时间范围：同日、跨日、非法顺序、默认结束时间、全天和待定清理。
- 现有 `tools/time/js/*.test.js` 全量回归，所有脚本通过 `node --check`。

### 手机视口交互验收

1. 点击新增后 `quick-title` 为活动元素。
2. 编辑会话打开时背景不能滚动，列表左右滑动无响应。
3. 点击每个快捷按钮，只有一个面板可见；切换不关闭编辑器。
4. 时间、提醒、重复确认与返回都回到日期主面板。
5. 详细信息覆盖整个视口，返回后标题重新聚焦。
6. 点击蒙层和下滑关闭后，再次新增恢复草稿。
7. 保存成功清除草稿并正确显示开始/结束范围。

### 真机重点

- iOS Safari 与主屏 PWA：首次点击呼出键盘、快捷面板替换键盘、详情返回再次呼出键盘。
- Android Chromium/PWA：返回键层级、滚动锁和滚轮触控。
- 桌面浏览器：Escape、焦点范围、键盘操作和窄屏响应。
