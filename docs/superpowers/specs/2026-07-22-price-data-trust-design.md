# 买前省省数据可信与体验优化设计

## 目标

在保留 Cloudflare Worker 短链解析和匿名共享价格历史能力的前提下，明确本地与服务器的数据边界，降低滥用、重复记录和异常价格污染风险，并修正 PWA 缓存、功能文案及基础可访问性问题。

## 范围

本轮包含：

- 短链展开的响应大小、超时和跳转安全控制。
- 快照写入的最小化上传、双重限流、去重和异常价格判断。
- CORS 默认策略和 Worker 自动化测试。
- README、设置页、心愿价与好物推荐的能力说明。
- Service Worker 资源版本与缓存匹配修正。
- 关注空状态及好物卡片的基础可访问性优化。

本轮不包含：

- 用户账号、登录、跨设备同步或管理员后台。
- 自动采集电商实时价格。
- 邮件、短信、Web Push 或系统级降价提醒。
- Durable Object、数据库迁移或人工价格审核系统。

## 数据边界

### 仅在本地保存

- 用户填写的价格备注。
- 关注目标价和关注状态。
- 本地商品、价格快照、操作日志及导入导出内容。

### 请求期间传给 Worker

- 用户粘贴的分享文本或短链，用于当次平台识别和短链展开。

分享文本与原始短链不得写入 KV、日志对象或价格历史。响应可以将解析后的规范链接返回给浏览器，但不会作为共享价格历史数据保存。

### 可保存到服务器

- 平台代码。
- 商品 ID。
- 最多 200 个字符的规范化商品标题。
- 有效价格。
- 由服务器生成的采集时间。

前端不得向快照接口发送用户备注。Worker 即使收到旧客户端的 `note` 字段，也应拒绝该请求，而不是静默保存。

## 架构方案

采用 Cloudflare 原生 Rate Limiting binding 加现有 KV 存储，不引入 Durable Object。

Worker 使用两个限流绑定：

- `SNAPSHOT_CLIENT_LIMITER`：每个匿名客户端每分钟最多 12 次快照写入。
- `SNAPSHOT_ITEM_LIMITER`：每个平台与商品 ID 组合每分钟最多 30 次快照写入。

浏览器首次需要上传快照时生成 `crypto.randomUUID()`，存入 `localStorage`，并通过 `X-Price-Client-ID` 请求头发送。该 ID 只作为匿名限流键，不写入商品或快照 KV。清理本地存储可以生成新 ID，因此该机制用于抑制普通滥用和失控客户端，不宣称能抵御有意绕过的攻击者。

限流 binding 缺失时，`POST /snapshot` 返回 `503 rate_limit_unavailable`，采用失败关闭策略。解析和历史读取接口不受快照写入限流故障影响。

## 快照数据质量

### 输入规范

- `platform` 必须是 `jd`、`taobao`、`tmall` 或 `pdd`。
- `itemId` 长度为 1 到 128 个字符。
- `finalPrice` 必须大于 0 且不超过 1,000,000。
- `title` 可选，规范化连续空白后最多保留 200 个字符。
- 采集时间始终使用 Worker 当前时间；忽略并停止接受客户端 `capturedAt`。
- 请求体仅允许 `platform`、`itemId`、`finalPrice`、`listPrice`、`promoPrice`、`couponPrice`、`stockStatus` 和 `title`。

### 去重

同一平台、商品 ID 和精确到分的最终价格，在服务器最近一次相同记录后的 10 分钟内视为重复。重复请求返回 `200`，并包含 `deduplicated: true`，不追加新快照。

KV 是最终一致存储，因此该去重是尽力而为，不承诺并发请求下的强一致。客户端与商品双重限流将降低并发竞争窗口。若未来需要强一致，再单独迁移到 Durable Object。

### 异常价格

当商品已有至少 5 条有效快照时，计算最近最多 50 条快照的中位数。新价格低于中位数的 25% 或高于中位数的 4 倍时，返回 `422 suspicious_price`，不写入历史。

该判断只用于拦截明显误填或污染，不把共享历史描述成平台官方价格。历史最多保留最近一年和最新 500 条。

## 短链展开

- 保留 `GET` 请求，以兼容不支持 `HEAD` 或依赖 HTML 跳转的平台。
- 8 秒超时覆盖响应头和响应体读取全过程。
- HTML 响应最多读取 256 KiB；超限后取消读取并返回可重试错误。
- HTTP `Location`、meta refresh 和受支持的 JavaScript 跳转统一通过 `new URL(target, currentUrl)` 解析。
- 最多跟随 5 次跳转，且每轮只请求已知电商短链主机；跳到未知主机时停止，不继续发起外部请求。

## CORS 与接口行为

- `ALLOWED_ORIGINS` 缺失或为空时默认拒绝请求。
- 只有显式配置 `*` 才开放任意来源。
- 没有 `Origin` 的同源请求使用请求 URL 的 origin 做白名单判断。
- CORS 允许请求头增加 `X-Price-Client-ID`。
- `429` 响应包含稳定错误码和 `retryable: true`。

## 前端与文案

### 隐私说明

设置页增加“隐私与数据”说明：

- 商品记录、备注、心愿价默认保存在当前浏览器。
- 解析短链时会把分享文本或链接发送到服务器处理，但不会保存原始内容。
- 用户主动记录价格时，可匿名贡献商品标识、标题和价格到共享历史；备注不会上传。

README 同步描述该混合架构，删除“纯前端”“不实现短链展开”“价格记录不上传”等过期内容。

### 能力承诺

- “降到目标价会提醒你哦”改为“保存在关注列表，方便以后回来比较；当前版本不提供自动降价通知”。
- 按钮“加入关注”改为“保存心愿价”。
- 好物页明确标注为“示例数据”，徽章改为演示语义，避免被理解成实时优惠。

### 交互与可访问性

- 关注空状态增加“去查价”按钮。
- 好物卡片使用原生 `button` 或等价键盘可操作语义，并保留可见焦点。
- 为关注、好物和设置视图补齐真实存在的 `aria-labelledby` 标题。
- 隐藏的主题单选控件在键盘聚焦时通过关联标签显示焦点样式。

## PWA 缓存

- HTML 与 Service Worker 中的价格工具资源统一升级到同一版本号。
- 更新价格工具缓存名称，确保旧缓存被清理。
- 资源匹配不再忽略查询参数，使版本化 URL 能准确失效。
- 页面导航保留离线回退，静态资源继续使用缓存优先并后台更新。

## 错误处理

- 前端继续先写入本地数据；匿名共享写入失败不丢失本地记录。
- 限流、异常价格或服务器不可用不会阻断本地记价，但应以非侵入提示说明“已保存在本地，未同步到共享历史”。
- 短链解析失败继续退回本地解析，并给出手动记价引导。

## 测试与验收

- Worker 单元测试覆盖 CORS 缺省拒绝、显式通配符和无 Origin 同源请求。
- Worker 路由测试覆盖客户端限流、商品限流、缺失 binding、最小请求字段、服务器时间、重复写入、异常价格和历史上限。
- 短链测试覆盖 `GET`、相对跳转、HTML 大小限制和完整超时。
- 前端测试覆盖匿名客户端 ID、快照请求不含备注，以及同步结果状态转换。
- 现有链接解析、价格判断、导入导出测试保持通过。
- 移动端验证首页、分析页、关注空状态、好物页和设置页，并检查键盘焦点及深色主题。

## 部署要求

- Wrangler 增加两个独立的 `ratelimits` binding，使用互不重复的正整数 namespace ID。
- 生产环境必须保留明确的 `ALLOWED_ORIGINS`。
- 部署前执行 Worker 测试、前端测试、语法检查、`git diff --check` 和 Wrangler dry-run。
