# Quick Tools - 生活账单模块 产品设计文档

> 文档版本：v1.0  
> 创建日期：2026-06-09  
> 产品阶段：新模块（在现有 Quick Tools 网站中新增）  
> 复杂度：中等

---

## 1. 需求背景

Quick Tools（`https://quick-tools-nine.vercel.app/`）目前已有文本对比和 JSON 工具两个模块。用户希望新增一个**生活账单**模块，用于记录和管理日常消费支出。

用户当前使用 Excel 表格记录账单，包含日期、消费对象、一级分类、二级分类、商品名称、购买渠道、金额、支付方式等维度。现有方式存在以下痛点：

- 每次记录需要打开 Excel，操作路径长
- 筛选统计需要手动操作数据透视表，不够直观
- 没有可视化的趋势分析和占比展示
- 数据存储在单一文件中，跨设备查看不便

通过新增网页版账单模块，用户可以在任何设备上快速录入和查看消费记录，同时保持数据隐私（本地存储）。

---

## 2. 产品目标

1. **3 秒完成记账**：从打开页面到保存记录不超过 3 秒
2. **多维度灵活统计**：支持按标签组合筛选，实时更新统计结果
3. **数据完全本地**：所有数据存储在浏览器本地，不上传服务器，保护隐私
4. **零门槛上手**：首次使用有清晰指引，无需学习成本
5. **数据可迁移**：支持导入/导出，便于备份和跨设备迁移

#### 5.2.2 快速录入

**页面布局（表单模式 - 默认）：**

```
+----------------------------------------------------------+
|  记一笔                                                  |
+----------------------------------------------------------+
|  模式切换: [表单录入 ●] [自然语言 ○]                      |
+----------------------------------------------------------+
|  金额: [        ¥ 0.00        ]  [计算器按钮]             |
|                                                          |
|  日期: [2026-06-09 ▼]                                    |
|                                                          |
|  标签: [+ 添加标签... ]                                   |
|        [#家庭] [#食品] [#餐饮] [×]                       |
|                                                          |
|  商品名称: [  小笼包 (可选)  ]                            |
|                                                          |
|  [  保存记录  ]                                          |
+----------------------------------------------------------+
|  最近使用:                                               |
|  [家庭-食品-餐饮] [宝贝-购物消费-玩具] [家庭-生活-家居清洁] |
+----------------------------------------------------------+
```

**页面布局（自然语言模式）：**

```
+----------------------------------------------------------+
|  记一笔                                                  |
+----------------------------------------------------------+
|  模式切换: [表单录入 ○] [自然语言 ●]                      |
+----------------------------------------------------------+
|  输入消费信息:                                            |
|  +--------------------------------------------------+    |
|  |  午餐 35 家庭 餐饮 叮咚                               |  |
|  +--------------------------------------------------+    |
|  解析结果:                                               |
|  金额: ¥35.00 | 标签: #家庭 #餐饮 | 商品: 午餐 | 渠道: #叮咚 |
|                                                          |
|  [  确认保存  ]                                          |
+----------------------------------------------------------+
```

**功能描述：**

- **模式切换**：通过开关在"表单录入"和"自然语言"两种模式间切换，切换时保留已输入内容
- **金额输入**：数字键盘输入，支持小数点，自动聚焦
- **日期选择**：默认当天，可修改
- **标签添加**：
  - 输入框支持智能提示：输入"家"自动提示"#家庭"
  - 支持多标签，标签以 chip 形式展示，可点击删除
  - 常用标签置顶：最近使用过的标签排在前面
- **商品名称**：可选填写，用于搜索和明细展示
- **最近使用模板**：展示最近 3 组常用的标签组合，点击一键填充
- **自然语言解析**：
  - 输入示例："午餐 35 家庭 餐饮 叮咚" → 解析为金额 35、标签 #家庭 #餐饮 #叮咚、商品"午餐"
  - 金额识别：自动提取数字作为金额（支持"35""35.5""35.50"）
  - 标签识别：将已知标签从文本中提取，剩余文字作为商品名称
  - 解析结果预览：保存前展示解析结果，用户可手动修正

**交互逻辑：**

- 表单模式下，金额输入框自动聚焦，用户打开页面即可直接输入数字
- 按 Enter 键快速保存（表单模式下金额框按 Enter 保存，自然语言模式下解析框按 Enter 解析）
- 保存成功后，表单清空并保留日期，金额框重新聚焦，便于连续录入
- 标签输入支持逗号/空格/回车分隔，批量添加多个标签

#### 5.2.5 数据导入

**功能描述：**

- **支持格式**：Excel (.xlsx, .xls) 和 CSV (.csv)
- **导入流程**：
  1. 用户上传文件
  2. 系统解析文件，展示列名和数据预览（前 5 行）
  3. 用户将文件列映射到系统字段：
     - 日期列 → Date
     - 金额列 → Price（必填）
     - 其他列可选择映射为标签或忽略
  4. 用户确认映射关系
  5. 系统导入数据，展示导入结果（成功/失败条数）
- **标签自动映射**：
  - "消费对象"列（如"家庭/宝贝/老公/个人"）→ 自动转为对应标签
  - "一级分类"列（如"食品/购物消费"）→ 自动转为对应标签
  - "二级分类"列（如"餐饮/玩具"）→ 自动转为对应标签
  - "购买渠道"列（如"京东/山姆"）→ 自动转为对应标签
  - "支付方式"列（如"WeChat"）→ 自动转为对应标签
- **重复处理**：相同日期+金额+商品名称的记录视为重复，用户可选择跳过或保留
- **错误处理**：金额格式错误、日期格式错误的行标记为失败，提供错误原因

## 7. 技术方案

### 7.1 存储方案

- **IndexedDB**：使用 IndexedDB 存储账单记录和标签数据，容量大（通常 50MB+），支持索引查询
- **localStorage**：存储用户设置（主题、引导状态等）
- **数据备份**：通过 JSON 导出实现数据迁移

### 7.2 技术栈

- **前端**：纯 HTML + CSS + JavaScript（与现有项目保持一致）
- **图表**：使用 Chart.js 或 ECharts 实现饼图、折线图、条形图
- **日期处理**：原生 Date API
- **文件导入**：FileReader API 读取 Excel/CSV
- **文件导出**：Blob + URL.createObjectURL 实现下载

### 7.3 性能考虑

- 账单记录超过 1000 条时，列表采用虚拟滚动或分页加载
- 图表数据量较大时，采用数据聚合（按周/按月汇总）
- 筛选统计计算使用防抖，避免频繁渲染

| 8 | 演示模式 | 开启演示模式后加载 20 条示例数据，关闭后恢复真实数据 |
