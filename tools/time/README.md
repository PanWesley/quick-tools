# 今日有序

今日有序是 `tools/time/` 下的移动端优先本地 PWA，副标题为“日历、待办与习惯打卡，一起管理美好的今天。”它把待办、习惯、日历和每日一句收束到“今天”这个核心视图里，避免把轻量时间管理做成复杂项目管理系统。

## 产品定位

- 面向个人日常，而不是团队协作。
- 本地优先，无需登录即可使用。
- 首页优先回答“今天要做什么”，高级能力放在清单、日历和我的页。
- 数据安全优先，导出和导入恢复是同步能力之前的基础能力。

## 核心功能

- **今日待办**：展示今天和逾期未完成事项，支持标题、日期、时间点/时间段、归属、提醒偏好、四象限优先级和备注。
- **新增事项**：默认记录一次性事项，默认选中今天；安排顺序为今天、明天、周末、自定义、待定，选择待定时自动隐藏时间/重复/提醒字段。选择重复后自动生成习惯打卡。
- **时间选择**：时间点和时间段均使用自定义滚轮选择器，时间段自动预填结束时间为开始时间+1小时，避免原生控件样式不一致。
- **自定义重复**：除每天、工作日、周末、每周、每月外，支持按任意间隔（天/周/月）自定义重复，可选跳过法定节假日和双休日。
- **自定义提醒**：除准时、5/15/30分钟前、1小时前外，支持提前任意天/小时/分钟组合的自定义提醒。
- **归属筛选**：新增事项默认归属到生活，也可选择学习、工作、健康、家务、纪念和其他，并在清单页按归属筛选。
- **任务编辑**：任务创建后可继续修改标题、日期、时间、归属、优先级、重复、提醒和备注。
- **左滑操作**：任务条默认保持紧凑，左滑后显示编辑、删除或恢复操作。
- **习惯打卡**：支持每日、工作日、周末、每周、每月及自定义间隔计划的轻量打卡，待打卡区域以单列纵向列表展示。
- **日历标记**：按月展示任务、习惯和每日一句，支持收起月历来查看日期详情。
- **农历与节气**：日历格展示农历日、农历月初和常见节气，减少只看星期带来的信息缺口。
- **手账月视图**：日历页以柔和彩色条展示当天任务、习惯和每日一句；已完成或已打卡内容会暗化并划线。
- **每日一句**：为当天保存一句状态、收获或想法。
- **清单整理**：在同一个整理工作台里切换全部、未安排、即将到来、已过期、已完成和已删除，支持按归属下拉筛选和关键词搜索。
- **全部任务视图**：清单默认展示全部任务与习惯，按日期分组（已过期/未安排/今天/明天/以后/循环习惯），任务显示优先级圆点，习惯显示循环图标（颜色对应优先级）。
- **左滑操作统一**：任务左滑显示编辑、删除；习惯左滑显示编辑、跳过；已删除项左滑显示恢复、彻底删除。
- **最近删除**：任务删除后保留为软删除状态，可从清单页恢复，也可彻底删除。
- **任务搜索**：清单页顶部搜索框支持按任务标题或备注关键词快速查找。
- **系统通知提醒**：添加到桌面后支持系统级通知，每个任务/习惯按设置的提醒时间弹出通知；在「我的」页授权并开启后生效；应用切回前台时自动检查漏掉的提醒并汇总通知。
- **JSON 导出**：导出 tasks、habits、habitLogs、journals、opLogs。
- **JSON 导入恢复**：校验 `app: "today-youxu"` 和 `version: 1`，按 `id` 合并记录，优先保留 `updatedAt` 更新的数据，并记录导入 OpLog。

## 视觉方向

- 当前主题为“晨光手账”：晨橙、珊瑚粉、薄荷绿和暖白背景。
- 日历页参考手账式月视图，使用轻量彩色条承载事项，不把详情卡片堆得过重。
- 字号、字重和卡片密度偏轻量化，移动端避免大标题和空面板占用过多空间。
- 任务条使用四象限优先级配色：重要且紧急、重要不紧急、不重要但紧急、不重要不紧急分别映射到不同的条目边线、底色和标签。
- 任务详情使用紧凑行布局，移动端通过左滑露出操作，桌面浏览器通过悬停露出操作。
- 清单页使用「整理任务」工作台，顶部搜索 + 状态 tab + 归属下拉筛选，列表按日期分组，任务用优先级圆点、习惯用循环图标标记，第二行显示时间和连续打卡天数。
- 新增事项使用居中弹窗，安排顺序为今天、明天、周末、自定义、待定；时间支持全天、时间点和时间段，时间、重复、提醒均使用自定义滚轮选择器，重复方式决定是否生成习惯。
- 我的页提供晨光橙、浅蓝、浅绿和深色主题预设，并复用生活账单的问题反馈邮箱。
- 输入框、日期选择和备注控件保持 16px 字号，避免 iOS Safari 聚焦输入时自动放大页面。

## 数据与隐私

- 本地数据库：IndexedDB `todayYouxuDB`。
- 本地偏好：复用站点主题偏好 `quick-tools-theme`。
- 默认不需要账号，不上传待办、习惯、日记或备注内容。
- 页面接入站点级匿名统计脚本，仅用于工具打开、路由和活跃时长等匿名指标；用户输入内容不进入统计事件。
- 登录同步和 Web Push 目前只是后续能力入口，MVP 不依赖远端服务。

## 文件结构

```text
tools/time/
├── index.html              # 页面结构和 PWA 入口
├── manifest.json           # 独立 PWA manifest
├── sw.js                   # 今日有序独立 Service Worker
├── README.md               # 工具说明
├── CHANGELOG.md            # 工具变更记录
├── css/
│   └── style.css           # 今日有序样式
└── js/
    ├── app.js              # 页面交互和视图渲染
    ├── app-state.js        # 本地数据选择器和日历状态
    ├── date-utils.js       # 日期工具
    ├── db.js               # IndexedDB 读写与 OpLog
    ├── export.js           # 导出数据结构
    ├── import-utils.js     # 导入校验与合并规则
    └── notification.js     # 系统通知服务（权限、调度、提醒）
```
