# Changelog

## v0.11.0 (2026-07-24)

### 新增
- 点击今日、日历日期详情和清单中的任务或习惯，可直接进入全屏详细编辑页；详情页底部“完成”负责保存。
- 详情页右上角新增“更多操作”菜单，可软删除任务或归档整个习惯；习惯历史打卡记录继续保留。
- 今日页将当天任务拆分为“待办事项”和“已完成”两个区域。

### 优化
- 今日页只显示日期范围覆盖今天的任务，已经结束的逾期任务不再混入今日。
- 习惯选择的背景色会统一显示在今日、日期详情、清单和日历条目中。

### 技术
- Service Worker 缓存升级至 v59；CSS v163、状态模块 v137、数据库 v137、主程序 v166。

## v0.10.1 (2026-07-24)

### 优化
- 移除快捷事项面板的装饰性滑动指示，压缩输入、工具栏和键盘之间的网页留白；44px 触控目标保持不变。
- 日期编辑改为独占底部弹层，新增整页“取消 / 确认”；时间、提醒、重复仍在二级面板完成后返回日期主页。

### 修复
- 日期设置现在使用临时会话：取消或 Escape 完整回滚，确认后一次性写回，并在返回时重新聚焦标题输入。
- 关闭整个事项编辑器时会丢弃未确认的日期临时状态，避免半提交。

### 兼容
- iOS 键盘上一项、下一项和完成栏属于系统界面，网页端不做不受支持的隐藏处理。

### 技术
- Service Worker 缓存升级至 v58；CSS v162、快捷编辑器状态 v3、主程序 v165。

## v0.10.0 (2026-07-22)

### 新增
- 新增事项改为单一编辑会话，支持开始/结束日期与时间、草稿恢复和真正全屏详情。

### 优化
- 快捷面板替换键盘区域；时间、提醒、重复完成后返回日期主面板。
- 编辑期间锁定背景滚动并暂停任务滑动操作。
- “待定”改为确认后再清理排期；弹层支持焦点循环、分层 Esc 返回和保存后回焦。

### 修复
- 修复 iOS 键盘弹出后仍可拖动快捷面板并带动底层页面的问题；主输入态现在完全锁定触摸滚动。
- 修复待定草稿重开后变为今天、任务或习惯背景色未保存的问题。
- 补足快捷编辑器背景隔离、日期范围调整提示和 44px 触控热区。

### 兼容
- 任务新增可选 `endDate`；旧任务缺少该字段时按单日事项处理。

  - **更多→全屏详情页**：点击更多按钮全屏展示详细编辑页面（返回/标题/完成导航，包含所有编辑项与结果预览，点击可跳转回对应快速选择面板。
  - **纸飞机保存按钮**：保留渐变圆形纸飞机按钮作为提交操作。

### 修复
- **JS运行时错误修复**：为移除的DOM元素引用增加null安全检查（closeAdd、quickFullSave等），避免空指针异常。
- **默认值修正**：优先级默认值恢复为 medium（重要不紧急/q2），归属默认值恢复为 life（生活），与历史行为保持一致。

## v0.6.0 (2026-07-10)

### 新增
- **系统通知提醒**：添加到桌面（PWA standalone模式）后支持系统级通知，每个任务和习惯按设置的提醒时间弹出系统通知。
- **通知权限管理**：「我的」页新增「系统通知」设置区，显示当前通知状态，支持一键授权通知权限和开启/关闭提醒。
- **多层调度策略**：前端定时器精确调度未来24小时内的提醒；每分钟自动检查并补充调度；应用切回前台时检查过去12小时内漏掉的提醒，弹出汇总通知。
- **Service Worker通知支持**：Service Worker新增通知显示、点击跳转和消息处理；应用未在前台时，必须由 Web Push 等事件唤醒后才能弹出通知。点击通知自动聚焦/打开应用并回到今日页。
- **通知去重机制**：通过localStorage记录已发送的提醒（48小时自动清理），避免重复通知；使用到期时间作为唯一标识，同一次到期只通知一次。
- **通知内容**：包含事项分类（工作/学习/生活等）、类型（任务/习惯）和距离到期的时间提示。
- **振动反馈**：通知触发振动模式[200ms, 100ms, 200ms]，移动端可感知提醒。

- 新增 `js/notification.js` 通知服务模块，封装权限管理、调度、通知显示和SW集成。
- Service Worker版本更新至v27，缓存新增notification.js脚本和最新CSS版本。
- 应用版本更新至0.6.0，manifest版本同步。
- app.js集成通知生命周期：数据加载后调度提醒、可见性变化时检查漏提醒、权限变化后刷新UI和重新调度。
