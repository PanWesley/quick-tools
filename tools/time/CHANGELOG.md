# Changelog

## Unreleased (2026-07-19)

### 优化
- **日历页重构**：参照「指尖时光」优化日历视觉，日期格卡片化，增加圆角和间距，高度增大容纳更多任务。
- **多彩任务条**：任务日历条按 ID 哈希分配稳定的暖色系背景色（桃/珊瑚/杏/奶油/薄荷/天空/淡紫/玫瑰等 10 色），左边框颜色表示优先级（高-红/中-橙/低-绿）。
- **显示更多事项**：日历格子最多显示 5 条事项（桌面端和移动端一致），超出显示 +N。
- **日期详情弹窗**：点击日历日期改为弹出底部/居中详情弹窗，内含关闭按钮、日期标题和右上角橙色 + 新增按钮，原页面内嵌详情区域在日历视图下隐藏。
- **日历占满屏**：日历视图改为 flex 布局，日历网格自适应占满剩余空间。
- **新增日期默认值**：在日历视图点击某天再点新增，事项日期默认预填为选中的那天。

### 技术
- Service Worker 缓存版本升级至 v33。

## Unreleased (2026-07-12)

### 新增
- 新增独立 Notifications Worker、Notifications D1 迁移和每分钟 Cron 调度，实现 PWA 后台或关闭后的 Web Push 提醒；超过计划时间 15 分钟的提醒不再补发系统横幅。
- 新增安装级设备身份。`device_id` 对应浏览器/PWA 安装实例而非硬件，清除站点数据或重装后会变化，并为未来 nullable `user_id` 账号绑定保留字段。
- 通知标题、正文、tag 和点击目标使用 AES-GCM 应用层端到端加密，密钥只保存在 IndexedDB；后端仍可见提醒时间等调度元数据和 PushSubscription。
- 新增通知同步队列与 pending、unsupported、error 状态。本地任务和习惯 CRUD 与通知后端失败解耦，恢复网络后重试。
- 新增匿名送达回执，页面和 Service Worker 可跨上下文识别已显示的提醒；回执不含提醒内容并在 48 小时后过期。

### 修复
- 修复 iOS PWA 在设备凭据失效后长期停留在“需要重新授权”的问题：前台恢复或用户点击“重新连接”时会注册新设备并复用现有 PushSubscription，不再依赖旧订阅注销成功。
- 通知设置现在明确区分系统权限被拒、凭据失效、等待网络和普通连接失败；重连与提醒快照同步全部完成后才显示“后台提醒已开启”。
- 修复 iOS 主屏 PWA 后台推送只能显示模糊兜底文案的问题：v2 密钥改为可跨页面与 Service Worker 导入的本地 raw key 记录，新提醒自动升级为 v2 加密。
- 修复打开 App 后补发过时且重复的明确提醒：前台不再补调已经错过的提醒，计时器晚醒超过 60 秒时不显示，并检查后台回执与系统可见通知。
- 测试提醒现在发送完整、严格校验的加密载荷，通知栏直接显示“测试提醒 / 后台提醒已连接”。

### 技术与兼容性
- 后台通知同步使用 Web Locks 串行化页面与 Service Worker 生命周期；缺少原生 `navigator.locks` 时明确显示不支持。
- Notifications Worker/D1 与 Analytics Worker/D1 隔离，只允许复用无状态基础模块，不共享业务数据库或密钥。
- 修正旧版说明：Service Worker 只能由 Push 等事件唤醒，不能仅依靠现有 Service Worker 在本地到点后台定时。
- 本地 Node、Worker 测试和 Wrangler dry-run 已纳入发布验证；生产 Cloudflare D1、VAPID secrets、route、Cron/deploy 与 iOS/iPadOS、Android、桌面真机投递尚需外部验证，当前不声明生产后台提醒已可用。
- Notifications Worker 兼容加密版本 1 和 2；本次升级不需要 D1 schema migration。当前客户端修复发布为 PWA v33 资源，不需要再次修改或部署 Worker。

## v0.6.0 (2026-07-10)

### 新增
- **系统通知提醒**：添加到桌面（PWA standalone模式）后支持系统级通知，每个任务和习惯按设置的提醒时间弹出系统通知。
- **通知权限管理**：「我的」页新增「系统通知」设置区，显示当前通知状态，支持一键授权通知权限和开启/关闭提醒。
- **多层调度策略**：前端定时器精确调度未来24小时内的提醒；每分钟自动检查并补充调度；应用切回前台时检查过去12小时内漏掉的提醒，弹出汇总通知。
- **Service Worker通知支持**：Service Worker新增通知显示、点击跳转和消息处理；应用未在前台时，必须由 Web Push 等事件唤醒后才能弹出通知。点击通知自动聚焦/打开应用并回到今日页。
- **通知去重机制**：通过localStorage记录已发送的提醒（48小时自动清理），避免重复通知；使用到期时间作为唯一标识，同一次到期只通知一次。
- **通知内容**：包含事项分类（工作/学习/生活等）、类型（任务/习惯）和距离到期的时间提示。
- **振动反馈**：通知触发振动模式[200ms, 100ms, 200ms]，移动端可感知提醒。

### 技术
- 新增 `js/notification.js` 通知服务模块，封装权限管理、调度、通知显示和SW集成。
- Service Worker版本更新至v27，缓存新增notification.js脚本和最新CSS版本。
- 应用版本更新至0.6.0，manifest版本同步。
- app.js集成通知生命周期：数据加载后调度提醒、可见性变化时检查漏提醒、权限变化后刷新UI和重新调度。

## v0.5.0 (2026-07-08)

### 新增
- **全部任务视图**：清单页新增「全部」默认 tab，集中展示所有任务和习惯，支持按状态（未安排、即将到来、已过期、已完成、已删除）和按归属分类双维度筛选。
- **日期分组显示**：全部任务按「已过期 / 未安排 / 今天 / 明天 / 以后 / 循环习惯」分组，每组带标题和数量，快速定位不同时间维度的事项。
- **左滑操作统一**：任务左滑显示编辑/删除，习惯左滑显示编辑/跳过，已删除项左滑显示恢复/彻底删除，所有列表交互一致。
- **优先级标记**：任务显示优先级颜色圆点，习惯显示循环图标（颜色对应优先级），第二行展示时间/重复规则和连续打卡天数。
- **归属下拉筛选**：分类筛选从横向 tab 改为右侧下拉菜单，节省横向空间，点击展开全部分类（全部、生活、学习、工作、健康、家务、纪念、其他）。
- **分页加载**：任务列表支持分页，超出指定条数后显示「加载更多」按钮，避免一次性渲染过多条目。
- **彻底删除与恢复**：新增 `uncompleteTask`（撤销完成）和 `purgeTask`（彻底删除）数据操作，已删除项可恢复或永久清除。

### 体验
- 清单页顶部新增搜索框，支持按任务标题或备注关键词搜索。
- 分类 tab 区域支持左右滑动，右侧有渐变边缘提示可继续滑动。
- 清单页移除归属分类显示，因为顶部已有统一筛选入口，列表更紧凑。
- 习惯连续天数计算从今天向前追溯，最多统计 365 天连续打卡记录。
- 已过期任务和分组标题使用强调色，避免错过截止时间。
- 已完成任务标题加删除线并弱化颜色，视觉上与未完成任务区分明显。

## v0.4.0 (2026-07-08)

### 新增
- **自定义滚轮选择器**：时间、重复、提醒全部使用统一风格的滚轮选择器，替换原生 time input，视觉与指尖时光等主流时间管理 App 一致。
