# Changelog

## v0.3.5 (2026-07-06)

### 今日
- 任务条改为左滑显示编辑、删除或恢复操作，默认状态只保留完成、标题、日期和优先级信息。
- 优先级从高中低无调整为四象限：重要且紧急、重要不紧急、不重要但紧急、不重要不紧急。
- 四象限优先级映射到任务条边线、底色和标签色，打开首页时可以更快判断处理顺序。
- 新增、完成、删除等提示改为顶部轻提示，使用应用主色和更小字号，避免遮挡底部操作区域。
- 习惯打卡区域突出“打卡”主按钮，“跳过”改为轻量次级操作。

## v0.3.4 (2026-07-06)

### 日历
- 农历文字进一步缩小并弱化颜色，突出阳历日期序号。
- 非本月日期不再显示日期、农历和事项；整周都不属于本月时直接隐藏该周，避免月历底部多出一整排。

## v0.3.3 (2026-07-06)

### 日历
- 重新调整月历格布局，日期头固定为独立居中区域，任务增多时不再把公历和农历挤到格子顶部。
- 选中日期格改为淡橙背景矩形，当前日期或选中日期的公历序号使用橙色圆形高亮。
- 事项条保留在日期头下方独立区域，视觉更接近参考图里的手账月视图。

## v0.3.2 (2026-07-06)

### 日历
- 日历格日期后方从星期改为农历日期，月初显示农历月份，节气日显示节气名称。
- 2026 年 7 月等常见月视图可显示“小暑”“大暑”“六月”“初二”等信息，降低参考传统日历时的认知差。

### Bug Fixes
- 修复 iOS Safari 在首页或快速新增表单输入任务时页面自动放大且不易恢复的问题，表单控件字号固定为 16px。

## v0.3.1 (2026-07-03)

### 体验
- 下调移动端字号和字重，减少“大字加粗”的厚重感，让整体更轻快。
- 今日页移除顶部“新增”和“本地模式”，保留右下角悬浮新增作为唯一主入口。
- 清单页将“收集箱 / 即将到来”改为“未安排 / 之后要做”，并压缩空状态面板高度。
- 我的页标题简化为“设置”，条目视觉密度同步收紧。

### 日历
- 移除日历页外层“月视图”标题区，将翻月、回到今天和收起按钮放入日历卡片内部。
- 月历支持收起/展开，减少查看日期详情时的滚动压力。
- 日历事项不再额外显示小圆点，已完成任务、已打卡或跳过的习惯会暗化并划线。

## v0.3.0 (2026-07-02)

### 视觉
- 默认主题从深绿色工具感调整为“晨光手账”方向，使用晨橙、珊瑚粉、薄荷绿和暖白背景。
- 品牌图标、主按钮、悬浮新增按钮和底部导航同步为更明亮的暖色视觉。
- PWA `theme_color` 和 `background_color` 同步更新，安装后状态栏颜色更贴近新主题。

### 日历
- 月视图改为更高信息密度的手账式日历格，任务、习惯和每日一句以柔和彩色条展示。
- 日历顶部新增“今”按钮，可快速回到本月今天。
- 日期详情改为紧凑任务行，编辑和删除操作横向收口，避免单条任务占用过多屏幕空间。

### Bug Fixes
- 导入或异常数据导致任务标题为空时，界面显示“未命名任务”，不再暴露 `null`。

## v0.2.0 (2026-07-02)

### 本地可靠性
- 新增任务编辑能力，已创建任务可继续修改标题、日期、优先级和备注。
- 新增最近删除列表，任务删除后进入软删除状态，可从清单页恢复。
- 新增 JSON 导入恢复，导入前校验应用标识和数据版本，导入时按 `id` 合并记录。
- 导入合并优先保留 `updatedAt` 更新的数据，并为导入动作写入 OpLog。

### 体验
- 今日页顶部新增“新增”按钮，减少只依赖悬浮按钮的操作不确定性。
- 任务行新增编辑、删除、恢复操作区，清单整理路径更明确。
- 我的页新增“导入 JSON”入口，与“导出 JSON”形成备份恢复闭环。

### 技术
- 新增 `tools/time/js/import-utils.js`，将导入校验、统计摘要和合并规则拆成纯函数。
- 新增导入合并单元测试和最近删除排序测试。
- Service Worker 缓存新增导入工具脚本，并随资源版本更新。

## v0.1.0 (2026-07-02)

### MVP
- 新增今日有序 PWA，产品名为“今日有序”，副标题为“日历、待办与习惯打卡，一起管理美好的今天。”
- 支持今日待办、习惯打卡、日历标记和每日一句。
- 支持本地 IndexedDB 存储 tasks、habits、habitLogs、journals、opLogs。
- 支持 JSON 导出，为后续本地恢复和跨设备同步打基础。
- 接入工具首页、PWA manifest、Service Worker 和 Vercel 路由。
