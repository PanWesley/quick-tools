# Changelog

## v1.5.3 (2026-06-18)

### Improvements
- **问题反馈入口**: 设置页新增独立的问题反馈模块，位于"危险操作"与"关于"之间
- **邮箱复制功能**: 反馈邮箱地址支持点击复制，方便用户在其他设备上手动发送邮件
- **一键发送邮件**: 发送邮件按钮使用 `window.open` 打开，避免页面跳转
- **界面对齐**: 反馈模块采用标准 setting-item 布局（标题 + 描述），与其他设置项风格统一

### Version
- v1.5.2 → v1.5.3

## v1.5.2 (2026-06-17)

### Improvements
- **底部记账入口**: 将突出的悬浮圆形加号改为与底部 tab 统一的“记账”入口，并通过主色图标块保持重点
- **主题设置**: 右上角改为设置入口，主题切换移入设置页，支持浅色、深色、跟随系统
- **标签入口**: 标签管理从“更多”菜单移到底部 tab，底部保持 4 项导航

### Bug Fixes
- **导入标签即时刷新**: 文件导入创建标签后刷新标签内存状态；进入标签管理页时主动重新读取 IndexedDB，避免 PWA 主屏模式下必须刷新网页才显示标签

### Version
- v1.5.1 → v1.5.2

## v1.5.1 (2026-06-16)

### Bug Fixes
- **更多菜单关闭**: 点击更多菜单中的标签管理/设置选项后，弹出层自动关闭
- **导入标签同步**: 数据导入后新标签立即呈现在标签管理视图中
- **今年时间范围**: 概览页选择"今年"时间范围能正确筛选当年数据
- 新增 `last-7`（最近7天）时间范围筛选支持

### Version
- v1.5.0 → v1.5.1
