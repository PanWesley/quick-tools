# Changelog

## v1.5.7 (2026-06-24)

### Improvements
- **桌面端账单操作**: 宽屏电脑浏览器改为悬停或键盘聚焦显示编辑、删除按钮，避免依赖不易发现的鼠标左滑
- **移动端左滑保留**: 触控设备和窄屏浏览器继续使用左滑操作，兼顾手机与响应式调试场景
- **键盘可访问性**: 编辑、删除按钮支持键盘聚焦，并移除操作区错误的辅助技术隐藏状态

### Bug Fixes
- **左滑松手回弹**: 修复鼠标模拟左滑后，后续点击事件立即关闭操作区的问题
- **快速操作被拦截**: 点击抑制仅作用于账单内容区，不再吞掉左滑后快速点击编辑或删除的操作
- **手势中断残留**: 指针手势被系统取消时清理临时位移，避免条目停留在半滑状态

### Technical
- 新增账单手势判定与点击抑制回归测试
- 更新静态资源及 PWA 缓存版本

### Version
- v1.5.6 → v1.5.7

## v1.5.6 (2026-06-24)

### Improvements
- **统一弹框布局**: 编辑、删除、确认、重命名、合并和通用提示弹框统一改为屏幕居中展示
- **移动端弹框体验**: 弹框保留安全边距，标题和按钮区固定，中间内容区域独立滚动
- **账单详情查看**: 单击账单条目打开只读详情弹框，展示金额、项目、日期、分类和标签
- **明细标签精简**: 明细列表仅展示一个首要标签，优先选择“消费类型”分组标签
- **详情标签分组**: 账单详情按标签分组展示全部标签，保留完整信息且更容易辨认
- **账单操作简化**: 移除账单条目长按操作，编辑和删除统一收口到左滑操作
- **设置入口配色**: 右上角设置齿轮固定使用应用主绿色及统一焦点样式
- **问题反馈布局**: 手机端邮箱地址可自然换行，发送邮件按钮独占一行，避免文字被遮挡

### Technical
- 更新弹框打开动画及 PWA 缓存版本

### Version
- v1.5.5 → v1.5.6

## v1.5.5 (2026-06-23)

### Improvements
- **标签管理移动端布局**: 新建分组置于添加标签之前，添加标签改为先选分组再输入标签名称，移动端输入框不再被挤压
- **标签搜索**: 标签管理页新增搜索框，支持按分组名或标签名筛选
- **快速新建标签**: 分组标题新增快捷添加入口，可自动选中该分组并聚焦标签名称输入框
- **批量移动标签**: 支持勾选多个标签后批量移动到目标分组

### Bug Fixes
- **导入后标签管理为空**: 增加标签分组自愈逻辑，当分组表缺失或标签归属失效时自动恢复默认分组并修正标签归属
- **JSON 导入分组一致性**: 覆盖导入时同步清理旧分组，并在导入完成后执行标签分组完整性修复

### Technical
- 新增标签分组修复工具、单元测试和 2500 标签压力测试
- 更新 PWA 缓存版本

### Version
- v1.5.4 → v1.5.5

## v1.5.4 (2026-06-23)

### Improvements
- **移动端账单明细**: 明细页改为按月分组，月份头显示当月支出汇总，列表更贴近移动端账单浏览习惯
- **条目快捷操作**: 账单条目支持左滑或长按显示编辑、删除按钮，点击条目可复用编辑弹框查看和修改详情
- **标签直接展示**: 明细条目中直接展示已选标签，便于快速识别消费维度
- **分组标签选择**: 记账和编辑弹框的标签输入升级为按分组展示的下拉多选，支持搜索筛选
- **自定义标签同步**: 输入不存在的标签时可直接新建，并同步进入标签管理

### Technical
- 新增账单月份分组工具与轻量测试，降低列表分组逻辑回归风险
- 更新 PWA 缓存版本并缓存新增工具脚本

### Version
- v1.5.3 → v1.5.4

## v1.5.3 (2026-06-18)

### Improvements
- **问题反馈入口**: 设置页新增独立的问题反馈模块，位于"危险操作"与"关于"之间
- **邮箱复制功能**: 反馈邮箱地址支持点击复制，方便用户在其他设备上手动发送邮件
- **一键发送邮件**: 发送邮件按钮使用 `window.open` 打开，避免页面跳转
- **界面对齐**: 反馈模块采用标准 setting-item 布局（标题 + 描述），与其他设置项风格统一

- v1.5.2 → v1.5.3

## v1.5.2 (2026-06-17)

### Improvements

- **主题设置**: 右上角改为设置入口，主题切换移入设置页，支持浅色、深色、跟随系统
- **标签入口**: 标签管理从“更多”菜单移到底部 tab，底部保持 4 项导航
