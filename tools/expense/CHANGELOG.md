## v1.6.3 (2026-06-30)

### UX
- 概览页顶部时间、标签、金额和搜索筛选统一作用于总额、分类占比、TOP 5 和支出趋势。
- 分类占比新增分析维度选择，可查看全部分组，也可聚焦消费类型、支付方式、人员、渠道等具体标签分组。
- TOP 5 跟随同一个分析维度，不再固定读取旧分类字段。
- 支出趋势取消独立时间下拉，统一跟随顶部时间筛选，较长时间范围自动按月汇总。
- 顶部标签筛选在整组全选时显示紧凑分组标签，减少筛选栏拥挤。

### Performance
- Installed PWA startup now serves same-origin app shell assets from cache first and refreshes them in the background.
- Chart.js and SheetJS are no longer loaded during the default bookkeeping startup path; charts load when opening Overview, and SheetJS loads only for Excel import.
- Removed the remote font stylesheet import so first paint does not wait for Google Fonts.
- Default startup no longer pre-renders Overview charts or the detail list before those views are opened.

### Technical
- 新增概览图表聚合测试，覆盖全局筛选、分组聚合和趋势按月汇总。
- 更新 PWA 缓存版本。

## v1.6.2 (2026-06-29)

### UX
- 记账页和编辑页的标签选择器保持原有分组，但组内会按使用习惯排序，常用标签更靠前，减少滑动查找。
- 已选标签在对应分组中置顶，连续多选时能更清楚地看到当前选择。
- 账单明细按时间倒序展示时，同一天内后添加的账单会排在更前面。

### Tags
- 使用最近 90 天的标签使用次数作为主要排序依据，历史总使用次数作为兜底；未使用标签保持在后面并按名称稳定排序。
- 排序从本地账单实时统计，不新增数据库字段，导入或新增账单后会随数据自然更新。

## v1.6.1 (2026-06-29)

### UX
- 记账页和编辑页的标签入口改为底部多选面板，默认不唤起键盘，优先展示可选标签。
- 标签选择支持连续多选，选择后不自动关闭面板，并提供清空/完成操作。

- 标签管理页新增、重命名、移动和批量移动均按分组检查重名。
- 合并标签时显示分组上下文，避免同名标签难以区分。

### Mobile

- 打开标签选择面板时隐藏底部导航，避免与面板和键盘区域互相遮挡。

## v1.6.0 (2026-06-26)

### Data Safety
- 新增轻量数据安全中心：普通备份保持一步下载，高级能力默认收起。
- 支持指定本地文件自动保存，并在浏览器不支持时自动降级为手动备份。
- 支持可选密码加密备份，默认不加密，恢复时会按备份类型处理。
- 恢复前会检查备份内容并给出摘要，支持覆盖恢复或合并去重。
- 恢复过程使用安全快照与失败回滚，降低误导入、半恢复造成的数据风险。
- 新增备份提醒：距离上次备份较久或新增账单较多时，仅做轻提示，不打扰记账。
- 尝试启用浏览器持久化存储保护，减少浏览器自动清理本地数据的概率。

### UX
- 设置页新增“数据安全”卡片，同时保留“表格导入”的简洁入口。
- 首页仅在需要时展示备份提醒，页面保持轻便、自然、低配置负担。

## v1.5.7 (2026-06-24)

### Improvements
- **桌面端账单操作**: 宽屏电脑浏览器改为悬停或键盘聚焦显示编辑、删除按钮，避免依赖不易发现的鼠标左滑
- **移动端左滑保留**: 触控设备和窄屏浏览器继续使用左滑操作，兼顾手机与响应式调试场景
- **键盘可访问性**: 编辑、删除按钮支持键盘聚焦，并移除操作区错误的辅助技术隐藏状态

### Bug Fixes
- **左滑松手回弹**: 修复鼠标模拟左滑后，后续点击事件立即关闭操作区的问题
- **快速操作被拦截**: 点击抑制仅作用于账单内容区，不再吞掉左滑后快速点击编辑或删除的操作
- **手势中断残留**: 指针手势被系统取消时清理临时位移，避免条目停留在半滑状态

### Technical
- 新增账单手势判定与点击抑制回归测试
- 更新静态资源及 PWA 缓存版本

### Version
- v1.5.6 → v1.5.7
