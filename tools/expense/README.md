# Expense Tracker（生活账单）

纯前端个人记账工具，数据存储在浏览器本地 IndexedDB 中，无需注册、无需联网即可使用。

## 功能概览

- **📊 概览面板**：按月/自定义时间范围筛选，总支出/笔数/日均/最高单笔统计卡片，分类占比饼图、TOP 5 柱状图、近 7 天趋势折线图
- **➕ 快捷记账**：表单模式 + 自然语言模式双入口，智能标签建议，最近标签组合模板
- **📋 账单明细**：日期分组展示，搜索/分类/排序筛选，分页加载，内联编辑与删除
- **🏷️ 标签管理**：一级分组 + 二级标签层级体系，树状可折叠管理，颜色自定义，分组间移动标签，重命名/合并/删除
- **📥 数据导入**：CSV / Excel (.xlsx) 拖拽或选择导入，全字段可编辑预览，按行删除，批量清理无效记录，字段自动映射
- **📤 数据导出**：CSV 表格导出、JSON 完整备份
- **⚙️ 设置**：演示模式切换、数据清除、深色主题、PWA 离线支持
- **📱 移动端适配**：响应式布局、底部导航栏、底部弹出标签选择

## 版本历史

### v1.4.0 (2026-06-14)

**Bug 修复（演示模式）：**
- 修复无痕模式首次进入时标签计数为 0、概览数量不符的问题
  - 根因：首次初始化使用 `generateTestData()`（60-180 条随机数据）而非 `enableDemoMode()`（固定 20 条样本数据），两条路径不一致
  - 修复：统一使用 `enableDemoMode()` 作为首次初始化入口
- 修复演示数据日期不在当前月份导致概览页显示 0 的问题
  - 修复：`DEMO_SAMPLE_DATA` 改为 `getDemoSampleData()` 函数，动态生成当前月份的日期
- 修复关闭演示模式后默认标签（支付方式、人员、消费类型等）残留的问题
  - 根因：`disableDemoMode()` 无备份时调用 `initDB()` 重新创建了默认标签
  - 修复：无备份时保持空数据库，不再调用 `initDB()`
- 修复演示模式下"加载更多"可以加载超过 20 条数据的问题
  - 根因：`generateTestData()` 生成 60-180 条随机数据，而 `getExpenses()` 无分页限制
  - 修复：统一使用 `enableDemoMode()` 的固定 20 条样本数据

### v1.3.5 (2026-06-13)

**Bug 修复：**
- 修复演示模式关闭后自定义数据完全丢失的问题
  - 根因：`enableDemoMode()` 将备份保存在 IndexedDB settings store 中，但 `clearAllData()` 清空了所有 store，导致备份被一并清除
  - 修复：备份机制改为 `localStorage`，不受 `clearAllData()` 影响
- 修复演示模式关闭时 `importData` 调用错误的问题
  - 根因：`app.js` 的 `window.importData`（文件导入）覆盖了 `db.js` 的 `importData`（数据对象导入），`guide.js` 调用时传入普通对象但执行了文件导入逻辑
  - 修复：`app.js` 的 `window.importData` 添加参数类型检测，数据对象路由到 `db.js` 版本，文件输入路由到 UI 版本
