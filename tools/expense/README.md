# Expense Tracker（生活账单）

纯前端个人记账工具，数据存储在浏览器本地 IndexedDB 中，无需注册、无需联网即可使用。

## 功能概览

- **📊 概览面板**：按月/自定义时间范围筛选，总支出/笔数/日均/最高单笔统计卡片，分类占比饼图、TOP 5 柱状图、近 7 天趋势折线图
- **➕ 快捷记账**：表单模式 + 自然语言模式双入口，智能标签建议，最近标签组合模板
- **📋 账单明细**：日期分组展示，搜索/分类/排序筛选，分页加载，内联编辑与删除
- **🏷️ 标签管理**：一级分组 + 二级标签层级体系，树状可折叠管理，颜色自定义，分组间移动标签，重命名/合并/删除
- **📥 数据导入**：CSV / Excel (.xlsx) 拖拽或选择导入，全字段可编辑预览，按行删除，批量清理无效记录，字段自动映射
- **📤 数据导出**：CSV 表格导出、JSON 完整备份
- **⚙️ 设置**：演示模式切换、数据清除、深色主题、PWA 离线支持
- **📱 移动端适配**：响应式布局、底部导航栏、底部弹出标签选择

## 版本历史

### v1.2.0 (2026-06-11)

**核心新功能：标签层级体系（一级分组 + 二级标签）**
- 默认预设分组：支付方式、人员、消费类型、渠道、未分类
- 标签管理页面完全重构为树状结构：可折叠分组卡片，展开/收起分组
- 支持新建分组、重命名分组、删除分组（删除分组时子标签自动移到未分类）
- 支持在不同分组之间移动标签，自定义模态框选择目标分组
- 筛选弹窗重构：按分组分类展示标签，点击分组标题一键全选/取消全选
- 选中标签后筛选栏显示「分组 · 标签」格式方便识别
- 饼图新增「按分组聚合」切换：点击标题"按标签"/"按分组"可以切换聚合方式
- 智能标签建议列表中显示分组名称，方便快速识别
- **数据库升级：DB_VERSION 从 1 → 2，自动迁移原有标签到消费类型分组**

**体验优化：**
- 通用自定义模态框支持任意 HTML 内容，复用度更高
- 移动端适配树状布局缩进和分组操作按钮
- 分组显示标签个数和总支出笔数统计

### v1.1.0 (2026-06-11)

**新增功能：**
- 数据导入完整预览：全量可滚动列表，所有字段支持内联编辑（日期/金额/项目/标签）
- 导入记录逐行删除 + 一键批量删除无效行
- 重新验证按钮：编辑后实时刷新记录状态
- 独立子站点访问：`/tools/expense/` 可直接访问，无需从主页进入
- PWA 完整支持：manifest、iOS 图标、pwa.css/js 均可在子页面独立加载
- 绝对路径引用：带/不带尾部斜杠的 URL 均可正确加载资源
- 自定义确认弹窗（替换原生 confirm/alert）
- 新用户引导只显示一次（同一设备）

**问题修复：**
- 修复 Service Worker cache-first 导致手机端加载旧版 CSS
- 修复清除数据后演示数据未同步标记导致开关状态不一致
- 修复首次访问时"演示模式"开关与实际状态不匹配
- 修复标签弹窗在手机端位置遮挡
- 修复筛选栏金额范围输入框不对齐
