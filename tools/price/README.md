# 买前省省

买前省省是 `tools/price/` 下的本地优先买前查价 PWA，用于解析商品详情页链接、记录价格、判断当前价格区间，并管理本地关注目标价。商品和关注数据以当前浏览器为主；Cloudflare Worker 提供短链解析和匿名共享价格历史辅助能力。

## 已实现范围

- 本地优先，无需登录即可使用。
- 商品、备注、心愿价和操作记录保存在 IndexedDB `zhenjiaAssistantDB`。
- 支持京东、淘宝、天猫、拼多多商品详情页及常见短链解析。
- 支持示例商品体验完整流程，不依赖真实平台 API。
- 支持手动记录价格、查看本地价格曲线、生成真低价判断。
- 支持本地关注目标价，以及 JSON 导入导出备份；当前版本不提供自动降价通知。
- 用户主动记价时，可匿名贡献最小必要字段到共享价格历史。
- 接入独立 PWA manifest、Service Worker、根首页工具卡片和 Vercel 路由。
- 接入站点级匿名统计，只统计工具访问与活跃时长。

## 数据与隐私边界

### 保存在当前浏览器

- 商品记录和本地价格快照。
- 用户填写的价格备注。
- 心愿价、关注状态、导入导出内容和本地操作日志。

### 请求期间发送到服务器

- 用户粘贴的分享文本或短链，用于当次平台识别和短链展开。

原始分享文本和短链不会写入共享价格历史。

### 可匿名保存到共享历史

- 平台、商品 ID、最多 200 个字符的商品标题、价格和服务器采集时间。

价格备注和心愿价不会上传。匿名快照写入具有客户端与商品双重限流、10 分钟相同价格去重、异常价格拦截，以及一年/500 条历史上限。共享数据来自匿名用户手动记录，不代表电商平台官方价格。

## 判断口径

买前省省使用当前可用的本地历史和匿名共享历史做区间判断：

- 记录少于 5 条或有效价格不足时，显示“数据不足”。
- 当前价不高于本地历史最低价时，显示“历史低价”。
- 当前价低于近 90 天 P20 分位时，显示“近期低价”。
- 当前价位于近 90 天 P20-P70 区间时，显示“价格一般”。
- 当前价高于近 90 天 P70 分位时，显示“偏贵”。

## 明确非目标与降级行为

当前版本不实现自动抓取电商实时价格、优惠券抓取、CPS 转链、登录同步、邮件/短信/Web Push 提醒。心愿价仅保存在关注列表，供用户以后回来比较。

短链解析或共享历史不可用时，工具会降级为前端链接识别和本地记价；服务器同步失败不会影响已经保存到浏览器的数据。

站点级匿名统计只用于了解工具访问趋势，不采集用户填写的商品备注、关注目标价或导入导出内容。
