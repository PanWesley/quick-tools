# Changelog

## Unreleased

### Changed
- 明确本地数据、短链解析和匿名共享价格历史的数据边界。
- 心愿价改为本地关注用途，不再暗示当前版本提供自动降价通知。
- 好物推荐明确标注为示例数据，并改善关注空状态和键盘操作体验。

### Security
- 匿名价格写入增加客户端与商品双重限流、重复价格合并和异常价格拦截。
- 短链展开增加响应体大小限制、完整超时和安全的相对跳转处理。
- CORS 配置缺失时默认拒绝请求。

## v0.2.0 (2026-07-14)

### Added
- 新增底部导航 4 个 Tab：查价 / 关注 / 好物 / 我的
- 新增「好物推荐」页面，展示精选示例商品（后续接入后台个性化推荐）
- 新增「我的」页面，整合外观设置、数据管理、版本更新、问题反馈
- 新增 4 套暖色系主题色切换：薄荷奶绿、蜜桃粉、暖杏橘、薰衣草
- 新增主题模式切换：浅色 / 深色 / 跟随系统
- 新增顶部 Header 标题随底部 Tab 动态变化
- 新增版本号显示与更新日志入口
- 新增问题反馈邮件入口

### Changed
- 原「数据」页合并至「我的」页面
- UI 整体优化为柔雾奶油风，更女性友好
- 底部导航改为 4 项胶囊式毛玻璃样式
- 主题色系统升级为 CSS 变量 + data-palette 方案

## v0.1.0 (2026-07-03)

### MVP
- 新增买前省省 PWA，定位为本地优先的买前查价与真低价判断工具。
- 支持京东、淘宝、天猫、拼多多商品详情页链接解析，并对短链和不支持平台给出明确提示。
- 新增示例商品与本地价格历史，可在无真实 API 的情况下体验完整判断流程。
- 新增价格曲线、分位数判断、可信分数、原因说明和购买建议。
- 新增手动价格记录、本地关注目标价、JSON 导入导出和清空本地数据。

### Technical
- 新增 `link-parser.js`、`price-judge.js`、`export.js` 及对应 `node:test` 单元测试。
- 新增 IndexedDB 数据层、轻量 SVG 价格曲线、独立 manifest 和工具级 Service Worker。
- 接入根首页工具卡片、根 manifest shortcut、根 Service Worker 预缓存和 Vercel 路由。
- 接入站点级匿名统计，按 `price` 工具标识记录访问趋势，不采集商品链接或价格记录内容。
- 修复示例商品手动记录后丢失示例历史的问题，确保图表和判断继续使用完整历史。

### Boundaries
- 首版不启用真实采集、优惠券抓取、CPS 转链、登录同步或外部提醒。
- 所有用户价格记录、关注目标价和备份数据均保留在本地浏览器中。
