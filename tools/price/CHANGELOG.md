# Changelog

## v0.1.0 (2026-07-03)

### MVP
- 新增真价助手 PWA，定位为本地优先的买前查价与真低价判断工具。
- 支持京东、淘宝、天猫、拼多多商品详情页链接解析，并对短链和不支持平台给出明确提示。
- 新增示例商品与本地价格历史，可在无真实 API 的情况下体验完整判断流程。
- 新增价格曲线、分位数判断、可信分数、原因说明和购买建议。
- 新增手动价格记录、本地关注目标价、JSON 导入导出和清空本地数据。

### Technical
- 新增 `link-parser.js`、`price-judge.js`、`export.js` 及对应 `node:test` 单元测试。
- 新增 IndexedDB 数据层、轻量 SVG 价格曲线、独立 manifest 和工具级 Service Worker。
- 接入根首页工具卡片、根 manifest shortcut、根 Service Worker 预缓存和 Vercel 路由。
- 接入站点级匿名统计，按 `price` 工具标识记录访问趋势，不采集商品链接或价格记录内容。
- 修复示例商品手动记录后丢失示例历史的问题，确保图表和判断继续使用完整历史。

### Boundaries
- 首版不启用真实采集、优惠券抓取、CPS 转链、登录同步或外部提醒。
- 所有用户价格记录、关注目标价和备份数据均保留在本地浏览器中。
